# 시각화 — HTML 의 강점을 쓴다

textbook-html(R6)과 explain-html(E4)이 함께 따르는 지침이다.

정지 그림이면 **인라인 SVG**, 값을 움직여 보여줄 것이 있으면 **위젯**을 만든다.

쓸 만한 자리 예시:

- **CT 재구성** — 슬라이더로 투영 각도를 돌리면 이미지 도메인이 사이노그램으로 쌓이는 과정.
  각도 수를 늘려가며 역투영이 어떻게 수렴하는지.
- **최적화** — 손실 함수 곡면 위에서 경사하강 점이 학습률에 따라 어떻게 움직이는지
  (너무 크면 튀고, 너무 작으면 안 간다를 **글로 설명하지 않고 보여준다**).
- **신호·필터** — 컷오프를 움직이며 파형과 스펙트럼이 같이 변하는 것.
- **알고리즘** — 단계 버튼으로 자료구조의 상태를 한 단계씩 진행.
- **분포·통계** — 표본 수를 늘리면 히스토그램이 어떤 모양으로 가는지.

만들 때 지킬 것:

- **SVG 우선.** `class="svg-fg / svg-muted / svg-line"` 를 쓰면 라이트·다크가 자동으로 맞는다.
  JS 로 `<circle>` 의 좌표나 `<path>` 의 `d` 를 바꾸는 방식이면 색 문제가 없다.
- **픽셀 데이터가 필요할 때만 `<canvas>`**(사이노그램·이미지 재구성 등). canvas 색은 CSS 를
  못 따라오므로 `getComputedStyle(document.body).getPropertyValue('--fg')` 로 읽어서 쓴다.
- **자체 완결.** 계산도 인라인 `<script>` 안에서 한다. 라이브러리를 쓰지 않는다(textbook-html R2, explain-html E1 과 같은 제약).
- **위젯 없이도 페이지가 성립해야 한다.** 결론은 본문 글에 적고, 위젯은 그것을 확인하는 도구로 둔다.
- 슬라이더에는 **현재 값을 숫자로** 함께 보여준다. 조작 방법을 한 줄로 적는다.
