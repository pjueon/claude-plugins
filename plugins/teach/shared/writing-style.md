# 한국어 문체 — teach 스킬 공통

textbook-html 과 explain-html 이 함께 따르는 기준이다. 집필자는 쓰면서, 리뷰어는 검수하면서 같은 기준을 쓴다. 사용자가 직접 지적한 어색함이 기준이다 — 번역 느낌, AI 같은 과장,
어색한 섹션명, 이해하기 어려운 설명. 존댓말('~합니다')과 의미는 유지하고, 필요 이상으로 문체를 바꾸지 않는다.

**섹션명(h2·h3·박스 제목·`summary`·`data-title`)**
- 명사구로 끝낸다. "내적의 의미", "모범답안과 흔한 실수".
- 서술문("내적이 재는 것", "부호로 어느 쪽인지 안다"), 구어 질문("왜 굳이 다시 쓰나", "이 문제를 어떻게 푸나?"), 대구("엄격할 것인가, 관대할 것인가")는 쓰지 않는다.
- '그래서·그런데·그리고·이제'로 시작하지 않는다. 한 제목에 두 주제를 대시로 잇지 않는다.
- 단계 제목은 한 형태로 통일한다(전부 "~하기" 또는 전부 서술형).

**번역투·직역 은유 — 평이한 말로 푼다** (아래는 이 스킬로 만든 교재에서 사용자가 실제로 지적했거나 교정한 예다. 다른 주제에서는 같은 *부류*를 찾되 이 단어 목록을 금지어로 쓰지 않는다. 사용자가 지적한 표현이 정본이다.)
- 분류 문맥에서 '직선으로 가르다/갈리다' → '분류하다·구분하다·분리하다·나누다'. '대 보다' → '적용하다·대입하다'. '아픔' → '문제'. '교재의 허리' → '가장 중요한 파트'. '내적이 재는 것' → '내적의 의미'.
- 사용자가 직접 지적하지 않은 교정 예: '못 박다→고정하다·정하다', '~에 의해→~에서·~이므로', '~의 몫→~에서 다룹니다', '비싼 값을 치르다→비용이 늘어납니다'. 어휘 자체가 틀린 것이 아니라 문맥에서 어색할 때만 고친다('맞히다' 처럼 표준 어휘는 그대로 둘 수 있다).
- 교재 은유('교재의 허리·심장·뼈대·씨앗·열쇠', '아픔', '맛보기', '길', '그릇 모양', '손에 쥐는 것')는 쓰지 않는다. 핵심은 "가장 중요한 파트"처럼 직접 쓴다.
- 의인화('욕심·힘을 쓴다·밀어낸다·알아서 정한다·허락한다')와 감정어는 뜻을 직접 쓴다. "제약이 작용한다", "균형을 이룬다".
- 수학 용어를 정확히 쓴다: 두 식을 더해 사라지면 '상쇄'(약분 아님), '가능해', '최댓값·최솟값'(사이시옷).

**AI 같은 말투**
- '정직하게·솔직히', 문단 머리의 짧은 단정문("힘의 균형입니다."), '~의 이야기입니다', "A 하는 대신 B 를 치르게 합니다" 같은 대구, 과장('폭발', '낭떠러지', '완성')을 줄인다.
- 한 문장에 한 주장. "이유는 ~라서 ~때문입니다" 같은 이중 인과, 명사 나열로 끝나는 서술, 쉼표로 판단을 5개 이상 잇는 문장은 나눈다. 수식은 문장 중간을 끊지 않게 문장 끝이나 별도 줄에 둔다.

**일관성·표기**
- 같은 개념은 한 용어로("크기를 고정한다"로 통일). 본문·표·퀴즈 해설은 '~합니다' 체로 맞춘다(요약 박스처럼 의도한 곳만 예외).
- '해 보기'(띄어쓰기), 조사는 읽는 소리 기준: x⁽³⁾ 은(삼), ‖w‖² 은(제곱).
- 직선·점에 가·나·다·라 같은 이름을 붙이면 문장 안에서 "‘나’ 직선은"처럼 따옴표와 '직선'을 붙인다(대명사 '나'와 구분). 장이 달라 같은 이름이 다른 대상이면 장마다 맥락을 밝힌다.
- 같은 사실을 다른 장·페이지에서 인용할 때는 현재 문구와 맞춘다(버튼 이름, 박스 제목).

**자기완결** — 산출물(교재 본문, `authoring/` 문서, README, 설명문)에서 이 플러그인이나 스킬·에이전트를 직접 언급하지 않는다. 산출물은 플러그인 없이도 읽히고 이어 작업할 수 있어야 한다. 규약과 절차는 해당 문서 안에서 풀어 쓰고, 스킬·규칙 번호(`textbook-html`, `R1~R8`, `SKILL.md`)로 가리키지 않는다.

**분량(textbook-html)** — 한 페이지에 새 개념이 대략 4개를 넘고 뒷부분이 앞보다 훨씬 추상적이면(증명·일반화 등) 선택 읽기 부분을
`details.fold` 접는 상자로 옮기고, 접기 앞뒤에 "이 부분은 건너뛰어도 된다 / 뒤에서는 결과만 쓴다" 연결 문장을 둔다. 페이지 수를 늘리면 `kicker`·"페이지 N" 참조·`BOOK` 을 모두 다시 맞춰야 하니 먼저 접기를 고려한다.
