# 학습 노트 (튜터용 현재 상태 — 이력은 git log)

## 설정
- 주제 / 학습 유형(a·b·c) / 목표
- 학습자 배경: 아는 것 / 모르는 것
- 코드 분담: 학습자 몫 <많이|반반|적게> — 근거 한 줄 (바꿀 때만 갱신)
- 교재: 사용|생략 · 태그: 사용|미사용 · 언어
- 외부 프로젝트: <URL 또는 '원격 없음: 이름'> @ <SHA> · 범위   (로컬 경로 금지)

## 현재 위치
- N장 · 단계 — 장별 상태의 정본은 authoring/03-진행-장부.md (여기에 중복해 적지 않는다)
