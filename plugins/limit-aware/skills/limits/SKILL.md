# limits

아래 명령을 실행하고 출력을 사용자에게 짧게 요약한다. 수치는 직접 계산하지 말고 출력된 값을 그대로 쓴다.

```bash
python "${CLAUDE_PLUGIN_ROOT}/scripts/report.py" --session "${CLAUDE_SESSION_ID}"
```

- `한도 정보 없음`이 나오면 statusLine이 설정되지 않은 것이다. `/limit-aware:setup`을 안내한다.
- 페이스가 `빠름`이거나 95% 이상이면, 남은 작업량과 비교해 작업 범위를 줄이거나 사용자에게 알릴지 판단한다.
- 수치는 마지막 statusLine 갱신 시점 기준이다. `(N분 전 수치)`가 붙으면 그만큼 오래된 값이다.
