처음부터 읽기

이 교재는 이렇게 생겼습니다

한 장(chapter)은 여러 개의 화면으로 나뉩니다. 화면은 ← → 방향키나 아래쪽 버튼으로 넘깁니다. 어디까지 읽었는지는 이 브라우저에 저장되므로, 다음에 다시 열면 이어서 읽기가 나타납니다.

읽는 방법

  • 접힌 상자는 눌러서 펼치는 부분입니다. 더 깊이는 처음 읽을 때 건너뛰어도 되고, 모범답안은 스스로 해본 다음에 열어보세요.
  • 퀴즈는 반드시 풀어보세요. 해설에 본문에 없는 이야기가 들어 있습니다.
  • 점선 밑줄이 그어진 낱말은 마우스를 올리면 뜻이 나옵니다.
  • Before / After 탭이 있는 코드는 탭을 눌러 같은 자리에서 비교해 보세요.
