# 집필 오케스트레이션

커리큘럼 확정 뒤의 집필은 **메인이 오케스트레이터**다. 장 본문은 직접 쓰지도 리뷰하지도 않는다.

| 역할 | 누가 | 하는 일 |
|---|---|---|
| 오케스트레이터 | 메인 | 지시서 작성, 장부 관리, 판정 처리, 병렬 판단, **커밋**, 보고 |
| 집필 | `textbook-html:textbook-writer` | 장 하나 집필·자체 점검·지적 반영 |
| 리뷰 | `textbook-html:textbook-reviewer` | 독립 검수, PASS/FIX 판정 (수정 안 함) |

기획·커리큘럼·골격 세우기(SKILL.md 절차 1~3)는 사용자와 대화가 필요하므로 메인이 직접 한다.

## 진행 장부 — `authoring/03-진행-장부.md`

서브에이전트는 매번 빈 머리로 시작한다. 장 사이의 약속은 기억이 아니라 파일로 넘긴다.
골격 세우기 때 오케스트레이터가 만든다.

```markdown
# 진행 장부
## 미결 약속   | 약속 | 한 장 | 갚을 장 |   (갚은 장이 줄을 지운다)
## 용어·기호   | 용어/기호 | 정의한 장·화면 | 한 줄 뜻 |
## 장별 기록   ### N장 — 제목 (커밋 해시): 화면 목록 · 뒷장이 알아야 할 이름/시그니처 · 커리큘럼과 달라진 점
```

순차 모드에서는 집필자가, 병렬 모드에서는 오케스트레이터가 반영한다. 장부는 그 장의 커밋에 포함한다.

## 장 하나의 루프 (기본: 순차)

1. 지시서를 써서 집필 에이전트를 호출한다.
2. 집필 보고를 받아 리뷰 에이전트(새 인스턴스)를 호출한다.
3. PASS → 4. FIX → BLOCK 목록 **원문**을 집필 에이전트(수정 모드)에 전달하고 재리뷰. 최대 2회, 그래도 FIX 면 멈추고 사용자에게 보고한다.
4. 오케스트레이터가 probe 를 한 번 확인하고 **커밋**한다.
5. 한 줄 보고(장·화면 수·리뷰 라운드·커밋) 후 다음 장으로 이어 간다. "한 장 쓰고 멈춰"라고 했을 때만 멈춘다.

R8 은 리뷰 PASS 로 충족한다. 사용자에게 묻는 것은 2라운드 실패, 커리큘럼 수정이 필요한 발견, 정본 변경뿐이다.

**지시서에 담을 것:** skill·교재 루트·브라우저 절대경로, 장 번호, 모드, 병렬 여부, 사용자가 따로 정한 사항, (수정) BLOCK 원문, (리뷰) 집필 보고 원문. 장 내용은 옮겨 적지 않는다 — 에이전트가 커리큘럼을 읽는다.

**커밋:** 장 하나 = 커밋 하나(`docs/chNN.html`, `book.js` 변경분, 장부). 한국어 메시지, 예: `3장 집필: 정규화와 키 설계 (12화면)`. 런타임(`book.css`/`book.js` 로직) 수정은 별도 커밋으로 먼저 낸다.

## 병렬화 — 확실히 이득일 때만

순차가 기본인 이유는 "N장에서 다룬다" 같은 약속과 앞장 참조가 어긋나지 않게 하려는 것이다. 아래를 **모두** 만족하면 묶어서 병렬로 쓴다.

1. **의존 없음** — 묶음 안 장끼리 "앞장에서 받는 것"이 겹치지 않는다. 묶음 밖 앞선 장은 이미 커밋·장부 반영됐다.
2. **약속이 고정됨** — 묶음 안 장끼리 주고받을 것이 없거나, 이름과 형태까지 커리큘럼·장부에 적혀 있다.
3. 코드 누적 교재면 **정본이 있다.**
4. **이득이 크다** — 장당 대략 8화면 이상이고 둘 이상이다.

개념의 허리 장, 앞장 코드를 이어받는 장은 묶지 않는다. 판단이 서지 않으면 순차로 한다. 병렬이면 묶음과 근거를 한두 줄로 알리고 진행한다.

**절차:** 집필 에이전트를 한 번에 병렬 호출(지시서에 `병렬 모드`; `book.js`·장부는 건드리지 않고 보고로 반환) → 오케스트레이터가 `TERMS`·`BOOK`·장부를 한 번에 합침(용어 충돌은 여기서 잡아 해당 장을 수정 모드로 되돌림) → 장별 리뷰 후 묶음 **교차 검수** 1회 → 장 번호 순으로 장마다 커밋. 교차 검수에서 BLOCK 이 반복되면 남은 장은 순차로 돌아간다.

## 금기

- 장 본문을 직접 고치지 않는다. 오탈자도 수정 모드로 시킨다(장부·리뷰 이력 일치).
- 리뷰 PASS 없이 커밋하지 않는다. 집필자의 "통과했다"로 리뷰를 생략하지 않는다.
- 리뷰 지적을 요약하지 않고 원문으로 전달한다.
