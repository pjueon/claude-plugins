# 백로그

계획된 작업 큐다. 결함은 [bugs.md](bugs.md)에, 계획은 여기에 둔다.

- **우선순위는 `## 우선순위` 목록의 순서가 전부다** — 위에 있을수록 먼저 할 일. 순서를 바꿀 땐 이 목록의 줄만 옮긴다(상세 블록은 그대로 둔다).
- 번호는 전부 `1.`로 쓴다 — 마크다운이 1, 2, 3…으로 자동으로 매긴다.
- 상세는 `## 상세`에 **같은 제목**으로 키를 맞춰 둔다. 항목 추가 시 우선순위 1줄과 상세 블록을 함께 넣고, 완료 시 **둘 다 지운다**(이력은 git에 남는다).

## 작성 형식

```
## 우선순위
1. <제목 A>
1. <제목 B>

## 상세
### <제목 A>
- 동기: <왜 필요한가>
- 범위: <무엇을 만드는가 / 어디까지>
- 메모: <종속·결정 필요 등, 없으면 생략>
```
